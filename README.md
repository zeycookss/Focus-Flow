# 🎀 Features

## ⏱️ Focus Timer

- 25-minute focus preset
- 50-minute focus preset
- Custom timer duration
- Start / Pause / Reset controls
- Circular progress indicator
- Session completion feedback
- Timer settings saved automatically

---

## 📝 Today's Little Things ♡

- Add tasks
- Mark tasks as complete
- Delete tasks
- Live task progress counter
- Press `Enter` to quickly add a task
- Tasks remain saved after refreshing the page

---

## 🎯 Today's Focus

Set the main thing you're working on and keep it visible while you focus.

Whether it's:

- Physics
- A coding project
- An assignment
- Revision
- Or something you've been procrastinating for three days...

Put it here. 😭

---

## 💗 Daily Goal

- Set a daily focus-session goal
- Track completed sessions
- Heart-based progress indicator
- Automatically resets for a new day
- Progress is saved with LocalStorage

---

## 🫧 Focus Mode

When you actually need to lock in:

- Hide the decorative elements
- Hide unnecessary cards
- Enlarge the timer
- Keep your current focus visible
- Exit anytime with the button or `Escape`

Less scrolling. More doing.

---

## 🔊 Little Sounds

- Start sound
- Task completion sound
- Focus session completion sound
- Sound toggle
- Sounds are generated using the Web Audio API
- No external audio files required

---

## 🕐 Retro Clock

- Live 12-hour clock
- Current date
- Retro digital-display styling

# 𓂃 ࣪˖ ִֶָ𐀪 The Vibe

FocusFlow isn't trying to look like another serious productivity dashboard.

The interface combines:

- 💿 Y2K nostalgia
- 🫧 Glassmorphism
- 🌸 Pastel colors
- 🦋 Digital scrapbook aesthetics
- 📼 Old-tech inspired visuals
- 💻 Retro computer typography
- ✨ Stickers, flowers & little decorative details
- 🪩 Soft animations and interactive elements

The idea was simple:

> **What if a productivity app looked like something you'd actually want to open?**

---

# 🪄 Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Web Audio API
- LocalStorage
- SVG
- Google Fonts

No frameworks.  
No backend.  
No build process.

Just HTML, CSS, JavaScript and a questionable amount of pastel decoration. ♡
